# Code of Conduct

We want Atlas to be a place where careful, technical, good-faith work is easy to do and disagreement stays about the work.

## Our standard

Expected: being precise and specific; assuming good faith; giving and accepting review of code, methodology and data claims; crediting others; saying "I don't know" or "I was wrong".

Not acceptable: harassment, discrimination or personal attacks of any kind; sexualised language or attention; doxxing or sharing private information; deliberately misleading claims about what the software or data can do; promotion of specific trades, tokens or venues as investments.

Because this project handles financial data, one project-specific rule: **do not use the project's issues, discussions or pull requests to solicit investment, promote a token, or make price predictions.** Such content will be removed.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may temporarily or permanently ban contributors for repeated or serious violations. Report a concern privately to the maintainers through a private GitHub security advisory on this repository (Security tab, "Report a vulnerability"), stating that it is a conduct report; reports are handled confidentially. If the concern is about a maintainer, say so in the report.

## Scope and attribution

This applies to all project spaces and to individuals representing the project in public. It is adapted in spirit from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
